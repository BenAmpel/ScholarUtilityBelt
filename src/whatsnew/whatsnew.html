What's new in Scholar Utility Belt 1.0.0

This page opens once after the update and is stored inside the extension. It loads nothing from the network.

Free for everyone

  • Your own journal list. Upload a CSV of journals and a tier label for each, such as your department's A, B and C list, in Options. Matching venues get a badge with your label. The file stays in your browser.
  • Quick read links stay visible. Scholar's new Quick read link used to be hidden along with the PDF links. It now shows as a small button on the result.
  • Safer imports. Importing a library file, from the Library page or the popup, now merges with what you have instead of overwriting it, and keeps one backup so the Library page can undo it. BibTeX export now writes the right entry type with the venue, tags and abstract. Review projects are saved one at a time, so a second tab can no longer erase another project.
  • A switch for extra lookups. In the detailed view the extension looks up each result's DOI in public services to show open-access, funder, citation and dataset signals. Options has a new switch, "Look up extra signals", that turns this off. The README lists every service and what is sent.
  • The CatalyzeX "Code" badge is gone. It sent each result's title and link to catalyzex.com. The Data and Code badge that reads the result's own links stays.
  • Quick read filter. The results filter bar has a "Quick read" checkbox that keeps only results with Scholar's Quick read link (you need to be signed in to Google Scholar).
  • Lineage on request. Author profiles no longer load the large advisor and student dataset until you press "Look up lineage".
  • Fixes. Saving several papers at once no longer drops some of them, the bibliography checker no longer freezes on pasted text, sorting no longer keeps the page busy, and the extension tells you when a tab needs a reload after an update.

Added to Pro

These are part of Scholar Utility Belt Pro. They are included with the extension and unlocked by the 14-day free trial, a purchase or App Pass, for everyone. If you installed before Pro launched, the Pro features that existed then stay free for you; these newer ones are not covered. Start a trial from Options.

  • Review workspace. Import RIS, BibTeX and PubMed .nbib exports from other databases with a search log, a risk-of-bias grid (RoB 2, ROBINS-I, Newcastle-Ottawa and JBI-style checklists), a screening agreement report with kappa, an evidence matrix, and snapshots with a change log.
  • Result signals. Claim-evidence chips and reproducibility signals read from the snippet, and a reading order built from your own include and exclude terms.
  • Exports. Zotero (RIS and CSL-JSON), an Obsidian vault, a LaTeX citation pack (with an Open in Overleaf button that sends only when you click) and a Word or Docs reference list. A highlights and notes export is free.
  • Library tools. Collection packets to share a reading list, similar papers and a duplicate finder, and watch lists that check OpenAlex for new work.
  • Checkers. A bibliography checker for retractions, venue quality and duplicates, a tenure packet built from an author profile, and a librarian report that builds research-impact numbers for a list of researchers from OpenAlex (you confirm each match).
  • Optional AI. A triage card that runs on Chrome's built-in model on your device, and Ask my shortlist, which uses your own API key and shows what it will send before you confirm.

More from Purplelink

Free web tools from the same studio that makes Scholar Utility Belt. These are plain links: the extension never contacts purplelink.llc, and nothing here is added to Google Scholar pages.

  • BibTeX Validator checks a .bib file for syntax errors, dead DOIs, and wrong authors or years.
  • Citation Generator turns a DOI, arXiv ID, or ISBN into APA, MLA, Chicago, or IEEE.
  • LaTeX to Word converts a .tex file or project .zip into a manuscript .docx.
  • Paper Review is a pre-submission review by four AI reviewers, from $9. References are checked free first.
