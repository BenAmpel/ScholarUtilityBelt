What's new in Scholar Utility Belt 0.7.0

This page opens once after the update and is stored inside the extension. It loads nothing from the network.

Changes in this version

  • App Pass (optional). If you already subscribe to App Pass, you can turn it on in Options to unlock Pro with it. It is off by default and nothing contacts joinapppass.com until you turn it on.
  • 14-day free trial. New installs can try Pro free for 14 days from Options or from any locked feature. The trial goes through ExtensionPay, which asks for your email.
  • What stays free. If you installed before Pro launched, the Pro features that existed then stay free for you forever. Pro features added from now on need Pro for everyone, including existing users.
  • Review link. Options has a link to review the extension on the Chrome Web Store.

More from Purplelink

Free web tools from the same studio that makes Scholar Utility Belt. These are plain links: the extension never contacts purplelink.llc, and nothing here is added to Google Scholar pages.

  • BibTeX Validator checks a .bib file for syntax errors, dead DOIs, and wrong authors or years.
  • Citation Generator turns a DOI, arXiv ID, or ISBN into APA, MLA, Chicago, or IEEE.
  • LaTeX to Word converts a .tex file or project .zip into a manuscript .docx.
  • Paper Review is a pre-submission review by four AI reviewers, from $9. References are checked free first.
