Zotero

The Zotero Connector already saves single papers from a page. This is the bulk version: it also carries your tags, notes and collections. RIS keeps notes as child notes and PDF highlights as a second note; CSL-JSON puts your notes in the Extra field. Both files contain your private notes. Import with File, Import in Zotero.

Obsidian or Markdown vault

One note per paper with YAML properties, your notes, PDF highlights as quoted bullets, and an index note with [[links]] grouped by collection. File names come from the DOI, or from author, year and title, so exporting again overwrites the same files. Editing a title changes that paper's file name.

    Supports APA 7, MLA 9, Chicago 17 (bibliography form) and IEEE, for journal articles, conference papers and preprints. Anything else is formatted as author, year, title and link. Scholar results do not include volume, issue or page numbers, so these are left out. Titles are used as saved: APA and IEEE expect sentence case, so edit them if needed. Author names come from Scholar's author line, which usually gives initials. The preview shows plain text; the copied version has italics and hanging indents. Check each entry against your style guide before you submit.
